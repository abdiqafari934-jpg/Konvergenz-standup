# Team Standup Logger - Konvergenz Internship Assignment

This is a lightweight internal tool for team members to post daily standup updates.

## 🚀 Live Links
- **Live Portal (Frontend):** https://konvergenz-portal.onrender.com
- **Live API (Backend):** https://konvergenz-backend.onrender.com/standups
- **GitHub Repository:** https://github.com/abdiqafari934-jpg/Konvergenz-standup

## 🛠️ How to Run Locally

### 1. Backend (Python/Flask)
- Navigate to `backend` folder.
- Run `pip install -r requirements.txt`.
- Run `python app.py`.
- Server runs on http://127.0.0.1:8000.

### 2. Frontend (React)
- Navigate to `frontend-app` folder.
- Run `npm install`.
- Run `npm start`.
- App runs on http://localhost:3000.

## ✨ Features Implemented
- **Standup Form:** yesterday, today, blockers, and file attachments.
- **Live Feed:** Real-time updates via 10-second polling.
- **Productivity Dashboard:** Charts for posts per day and blocker frequency.
- **Weather Integration:** Real-time Nairobi weather integrated into every post.
- **Error Handling:** API failure notifications shown to the user.
